# J3K · 2026 毕业感谢作品

写给初中三年所有老师的感谢信，做成了一个可以互动的小网页：

**输取件码 → 箱盖掀开 → 箱子里躺着奖状、荣誉证书、感谢信（和一朵玫瑰）→ 点开慢慢读。**

支持 **中文 / Bahasa Melayu / English / தமிழ்** 四种语言，右上角切换；每封信都能朗读（AI 配音）。

## 怎么用

1. 打开网页（或直接双击 `index.html`）
2. 输入老师专属的**取件码**（见 `取件码一览.md`）
3. 箱盖掀开后，点箱子里的东西：**奖状**、**荣誉证书**、**感谢信**

给某位老师的直达链接：`index.html?code=取件码`，例如 `index.html?code=1362`。

## 里面有什么

| 文件 | 说明 |
|---|---|
| `index.html` | 整个网页（单文件，不需要构建） |
| `assets/bear_sprite.webp` | 3D 小熊的 12 角度序列帧（教满三年的老师箱里才有） |
| `voice/` | 四语 AI 配音（中文 21 分钟为完整版） |
| `取件码一览.md` | 28 位老师的取件码与科目 |
| `AGENTS.md` | 项目交接文档（结构、验证脚本、已知问题） |

## 说明

- 打印：奖状是 A4 横向、荣誉证书是 A4 纵向，证书页都有「打印 / 保存」。
- 朗读需要 `voice/` 里的音频文件，只拷 `index.html` 的话朗读会没声音。
- 字体走 Google Fonts，离线打开字形会回退。
